# ai-lab

## 먼작귀 칭구들

Windows와 Mac 화면 위에서 움직이는 데스크톱 캐릭터 앱입니다.
우사기춤, 치어리더 우사기, 모찌 먹는 랏코, 울먹이는 치이카와, 간식 먹는 치이카와,
클로버 치이카와, 춤추는 치이카와 등 **7종**을 선택할 수 있습니다.
마우스 따라가기, 클릭 정지·재생, 드래그 이동, 크기·속도 조절을 지원합니다.

### 다운로드 및 설치 · v0.4.2

| 운영체제 | 다운로드 | 지원 환경 |
| --- | --- | --- |
| Windows | [EXE 다운로드](https://github.com/kimjiwonpg98/ai-lab/releases/download/friends-v0.4.2/Meonjakgwi-Friends.exe) | Windows 10/11 · x64 |
| Mac | [DMG 다운로드](https://github.com/kimjiwonpg98/ai-lab/releases/download/friends-v0.4.2/Meonjakgwi-Friends-0.4.2-universal.dmg) | macOS 13 이상 · Apple Silicon / Intel |

- **Windows:** EXE를 다운로드해 실행하세요. 별도 설치나 Python 설치가 필요 없습니다.
- **Mac:** DMG를 열고 `먼작귀 칭구들.app`을 `Applications`로 드래그한 뒤 실행하세요.
- **사용법:** 캐릭터를 클릭하면 정지·재생, 드래그하면 이동, 우클릭하면 설정 메뉴가 열립니다.
- **숨기기·다시 표시·종료:** Windows는 작업 표시줄 알림 영역 아이콘, Mac은 메뉴 막대 🐰에서 조작합니다.

개인 배포용 앱으로 Windows 코드 서명과 Apple 개발자 인증서 서명·공증은 되어 있지 않습니다.
운영체제별 설치 안내와 검증 범위는 [프로젝트 README](usagi-desktop/README.md)를 참고하세요.
