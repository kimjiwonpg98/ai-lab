# Usagi Desktop

## 다운로드 및 설치

[macOS 설치용 DMG 다운로드](https://github.com/kimjiwonpg98/ai-lab/releases/download/usagi-v0.3.0/Usagi-Desktop-0.3.0-universal.dmg)

1. DMG를 열고 `Usagi Desktop.app`을 `Applications` 폴더로 드래그합니다.
2. 응용 프로그램에서 앱을 실행합니다. 메뉴 막대에 🐰가 표시됩니다.

macOS 13 이상, Apple Silicon·Intel 통합 빌드입니다. 현재 개발 머신에서 실행을 확인했으며
Intel 실기기와 macOS 13에서의 실행은 별도로 검증하지 않았습니다.
Apple 개발자 인증서 서명·공증이 없는 개인 프로젝트이므로 실행이 차단될 수 있습니다.
출처를 확인한 뒤 시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기로 승인할 수 있습니다.

## 기능

v0.3.0: **모찌 먹는 랏코**를 캐릭터 선택에 추가했습니다.
사용자 지정 영상의 56.70~58.30초 구간에서 추출한 48프레임을 30fps로 반복합니다.
테이블에 가려진 하체는 복원하지 않고 상반신과 앞의 디저트를 함께 남겼습니다.
배경 제거 경계와 반복 구간 전환이 일부 보일 수 있습니다.
기존 마우스 따라가기, 크기·재생 속도 조절, 클릭 일시 정지를 동일하게 지원합니다.

맥북 화면 위에서 춤추는 우사기 데스크톱 펫 시제품.
사용자가 지정한 유튜브 영상의 13.00~13.80초 구간에서 우사기를 분리한
24장의 투명 PNG를 30fps로 반복 재생합니다. 실제 영상의 팔·몸·고개 움직임을 사용합니다.
클릭하면 현재 프레임에서 일시 정지하고, 다시 클릭하면 이어서 재생합니다.
음악은 포함하지 않으며 실행 중 다운로드는 없습니다.

원본 확보 해상도는 514×360이며 캐릭터 자체는 약 100×140픽셀입니다.
크게 확대하면 경계가 거칠고, 일부 프레임에 작은 배경색 잔여물이 보일 수 있습니다.
전체 영상이 아니라 가림과 컷 전환이 없는 짧은 구간만 반복합니다.

## 실행

```sh
bash scripts/build.sh
open "dist/Usagi Desktop.app"
```

빌드에는 Xcode Command Line Tools, 실행에는 macOS 13 이상이 필요합니다.
생성된 앱을 Applications 폴더로 복사해도 됩니다. 로컬 임시 서명이며 공증된 배포용 빌드는 아닙니다.

설치용 DMG 생성: `bash scripts/package-dmg.sh`

## 조작

- 클릭: 춤 시작 / 정지
- 드래그: 이동 (위치 자동 저장)
- 우클릭 또는 Control-클릭: 메뉴
- **캐릭터 선택**: “영상 춤 우사기” / “치어리더 우사기” / “모찌 먹는 랏코” 전환. 선택은 재실행 후에도 유지됩니다.
  치어리더는 이전 PNG 이미지에 흔들림과 점프를 적용한 버전이며, 춤을 쉬면 대기 이미지로 바뀝니다.
  모든 캐릭터가 크기·속도 조절과 마우스 따라가기를 지원합니다.
- 메뉴 막대 🐰: 숨기기 / 다시 표시, 크기, 춤 속도, 위치 초기화, 종료
- **마우스 따라가기**: 우클릭 또는 메뉴 막대에서 켜기/끄기. 기본은 꺼짐이며 선택을 저장합니다.
  커서 옆으로 부드럽게 따라오고, 끄면 현재 위치에 머뭅니다.
  캐릭터 위에 마우스를 올리거나 마우스 버튼을 누르는 동안, 메뉴를 열거나 숨긴 동안에는 이동을 멈춥니다.
  “화면 구석으로 데려오기”를 선택하면 따라가기도 꺼집니다.

기본 무음이며 네트워크, 마이크, 화면 녹화, 접근성 권한을 사용하지 않습니다.
투명한 바깥 여백은 클릭을 통과시키며, 캐릭터 주변의 직사각형 영역은 마우스 입력을 받습니다.
전체 화면 앱 위 표시 여부는 macOS와 해당 앱의 윈도우 동작에 따라 달라집니다.
로그인 시 자동 실행과 음악 연동은 아직 구현하지 않았습니다.
이미지 출처는 [Assets/SOURCES.md](Assets/SOURCES.md)에 기록했습니다.

## 영상에서 다시 추출

`scripts/extract_dance.py`는 이 영상의 위치와 색상에 맞춘 전용 추출기입니다.
numpy, opencv-python-headless, pillow를 설치한 Python 환경에서 실행합니다.

```sh
python scripts/extract_dance.py /path/to/source.mp4
bash scripts/build.sh
```

`dance-contact.png`는 전체 프레임 검수용 이미지이며, `dance-preview.gif`는 동작 미리보기입니다.
랏코 추출: `python scripts/extract_rakko.py /path/to/rakko-video.mp4`

## 미리보기 생성

```sh
"dist/Usagi Desktop.app/Contents/MacOS/UsagiDesktop" --preview /tmp/usagi-preview.png
```
